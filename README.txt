# Translanguaging SEO Demo

This demo keeps the website as a strong one-page book website while adding SEO-focused content.

## Files

- index.html — page structure, SEO metadata and structured data
- css/custom.css — visual styling
- js/script.js — mobile menu + optional engagement events
- robots.txt — crawler instructions
- sitemap.xml — sitemap for the homepage

## Existing assets expected

Place these in the same site:

- /images/logo.png
- /images/book-cover.jpg
- /favicon.ico
- /contact.php

If your book cover has a different filename, change the two `/images/book-cover.jpg` references.

## Important before publishing

1. Replace `https://translanguaging.co.za/` with the real production URL if different.
2. Add a real Google Analytics 4 measurement ID if analytics is approved.
3. Add the actual research papers/repositories that support the final wording.
4. Do not claim a study proves something unless the study actually supports that claim.
5. Keep the visible FAQ text synchronized with the FAQ structured data.
6. Submit sitemap.xml in Google Search Console.
7. Test the site on mobile.
8. Test the contact form.
9. Verify every external link.
10. Run the final page through Google's Lighthouse/PageSpeed and Search Console.

## SEO structure demonstrated

The page targets search intent through useful sections such as:

- What Is Translanguaging?
- Why Is Translanguaging Important?
- 10 Translanguaging Strategies for Teachers
- Translanguaging in the Classroom
- What Does Research Say About Translanguaging?
- Frequently Asked Questions
- The Book

These are sections of one page for the demo. If a topic later deserves its own search landing page, it can be moved to a real URL such as:

/what-is-translanguaging/
/translanguaging-strategies/
/translanguaging-research/

Do not use changing URL fragments as fake SEO pages.
